# Z3-Launcher 1.1.0

This minor release improves the first-launch experience on Windows and Linux.

- Automatically detect the operating system language when no language preference has been saved.
- Select English, French, German, Spanish or Italian according to the detected locale.
- Fall back to English when the system language is unsupported or unavailable.
- Keep manually selected language preferences across restarts.
- Improve saved-language handling and add regression tests.

Available packages: Windows x86_64 ZIP, Linux x86_64 native TAR.GZ, AppImage and experimental Flatpak.

A compatible user-provided ROM is required to generate Zelda 3 resources. No ROM or Nintendo game assets are included.
