# Z3-Launcher 1.0.0

First stable release of Z3-Launcher for Linux and Windows.

- Forest-themed interface with gold controls and multilingual support.
- Download and launch Zelda 3; import game resources from a compatible user-supplied ROM.
- Configure gameplay, graphics, audio, keyboard and gamepad controls, shortcuts and zelda3.ini.
- Automatically save settings, with contextual status messages and capture controls.
- Centered column separators, readable shortcut labels and scrolling layouts.
- Linux native archive, AppImage, Windows archive and Flatpak packages.

A compatible ROM is required to generate game resources. No ROM or Nintendo game assets are included.

Original authorship and licenses are retained; new project work uses GPL-3.0-or-later.
